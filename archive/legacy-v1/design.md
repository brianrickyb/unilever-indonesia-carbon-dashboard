# Unilever Indonesia — carbon analysis

An independent analysis of published PT Unilever Indonesia Tbk sustainability reports, 2021–2025. Not an official Unilever product.

## System
Modern minimal research workbench. Horizontal masthead and report navigation; wide primary chart with a narrow evidence column; ruled numerical rows and source tables instead of repeated rounded cards. Use the existing Space Grotesk / Inter font stack and named blue, ink, muted, paper, amber and teal tokens. No decorative images, gradients, shadow-heavy panels, card grids or promotional copy. Roman headings, restrained scales, tabular numerals, thin dividers. No reveal animations.

## Product hierarchy
Overview: selected year, official operational figures, five-year trend and reporting limitations. Analytics: alternative metric trends and source composition. Insights: evidence and implications with explicit alerts. Plan: proposed actions and optional assumptions on reported fuel/refrigerant components. Method: every report, source page, raw status and boundary notes. Supplementary calculator: an empty, separate internal activity scenario, never mixed into the published inventory.

## Data contract
Primary Scope 2 table dashes stay null and display as a dash, with secondary zero values explained in source notes. Scope 3 is reported for 2021; unavailable years are gaps. No connected line across missing years. Operational totals are reported subtotals, never called a complete footprint. Manufacturing intensity is not divided into organisational totals to infer production. 2025 boundary changes remain visible. User assumptions never change report data.

## Responsive and accessible
Year buttons and nav wrap in a grid at narrow widths. Charts use responsive SVG with visible value labels and accessible descriptions. Data tables scroll within their own container. Focus rings are immediate. All report links identify year and printed page. Controls use native selects, buttons and labelled inputs.
